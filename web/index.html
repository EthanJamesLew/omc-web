      What works today
      
    
        
  • The OpenModelica bootstrap compiler is loaded as WebAssembly (~7 MB).
    • 
        
  • Your Modelica source is written into the wasm filesystem and OMC is invoked.
    • 
        
  • OMC's argv parsing, file I/O, and front-end parser run.
    • 
      

      
What doesn't yet:

      
    
        
  • The bootstrap variant stubs CevalScriptBackend.translateModel,
            so the full compile pipeline (backend → simulation code → wasm-clang → run) is incomplete.
            You'll see OMC's own error message, not a simulation result.
    • 
        
  • The Modelica Standard Library isn't bundled in the VFS yet, so
            import Modelica.Constants.g_n can't resolve.
    • 
        
  • OPENMODELICAHOME isn't wired, so built-in classes (Real, Integer…)
            come from the parser's hard-coded set only.
    • 
      

      
See omc-web/ROADMAP.md in the repo for the remaining milestones.
