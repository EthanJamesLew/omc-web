      How this works
      
Build runs omc.wasm (the OpenModelica
      compiler, compiled to WebAssembly) on your Modelica source in MEMFS.
      Output is the same 30+ C files OMC would emit natively
      (BouncingBall.c, _model.h, kernel splits,
      init.xml, makefile, …). Use Download C as .zip to get them.


      
Run loads a pre-built BouncingBall.wasm
      — the per-model simulation binary that the OMC-emitted C is normally
      compiled into — and runs it against your stopTime /
      stepSize. Result is a MATLAB-v4 trace file, plotted in the
      table and downloadable.


      
Caveat: the per-model wasm is currently pre-built. Modifying
      the model significantly (different number of state variables, new
      equations) means the prebuilt won't match. A genuine in-browser
      C→wasm step (e.g. bundling emception) is the
      next milestone.
