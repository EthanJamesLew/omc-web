      How this works (and what's still TODO)
      
Clicking "Compile & simulate" drives two paths in parallel:

      
    
        
  1. omc.wasm — the OpenModelica bootstrap compiler runs over your
            source. Today it parses, opens the file, and hits its stubbed
            CevalScriptBackend.translateModel — that's why the
            output panel still shows OMC's "Error processing file:"
            diagnostic. This is the same code that, with the remaining
            milestones below, will eventually produce simulation output
            for arbitrary Modelica models.
    2. 
        
  2. Built-in JS solver — a small registry of known models
            (BouncingBall + a trivial integrator) runs hand-written
            numerical equivalents with RK4 + event detection. THIS is what
            produces the plot you see. Parameter overrides in your source
            (e.g. parameter Real e = 0.7) are picked up via
            regex and actually fed to the solver.
    3. 
      

      
Remaining work for path 1 to produce the same plot:

      
    
        
  • Wire OPENMODELICAHOME so OMC's classloader finds built-in classes.
    • 
        
  • Bake the Modelica Standard Library into the VFS.
    • 
        
  • Replace stubbed CevalScriptBackend, Backend, and SimCode with real impls.
    • 
        
  • Bundle wasm-clang to compile generated simulation C into a per-model wasm.
    • 
        
  • Build sundials + simulation runtime as a static wasm archive.
