# common-shims/

Hand-written C overrides shared between `projects/omc-wasm/` and
`projects/sim-runtime/`. Single source of truth — neither project
should ship its own copy; per-target divergence (when needed) goes
behind `-DOMCWEB_TARGET_OMC` or `-DOMCWEB_TARGET_SIM` macros set by
each project's Makefile.

## Layout

| File                         | Purpose                                      | Consumed by               |
| ---------------------------- | -------------------------------------------- | ------------------------- |
| `omcweb_main.c`              | `__omc_main`: `MMC_INIT()` then `GC_disable()`, then user main. | omc-wasm                  |
| `omcweb_gc_stub.c`           | Boehm-GC API → libc malloc, no-collect. **Critical**: real GC corrupted argv in wasm. | both (linked into model wasms via omcweb_gc_stub.o) |
| `omcweb_rt_compat.c`         | Real-time / threading stubs (no-op on wasm).  | both                      |
| `omcweb_rt_compat.h`         | Companion header (forced via `-include`).     | both                      |
| `omcweb_stubs.c`             | Hand-written stubs for OMC runtime calls (Socket, embedded server, threadData fns). | omc-wasm |
| `omcweb_stubs_auto.c`        | Auto-generated by `tools/gen-stubs.py` from bootstrap headers. | omc-wasm |
| `omcweb_blas_extras.c`       | dcopy_, dnrm2_, ddot_, daxpy_, dscal_ — BLAS functions not in our cut-down LAPACK. | sim-runtime |
| `omc_config.h`, `omc_config.unix.h` | Replaces autoconf-generated config.        | omc-wasm                  |
| `antlr3config.h`             | ANTLR3 tweaks.                                | omc-wasm                  |
| `expat_config.h`             | expat tweaks.                                 | omc-wasm + sim-runtime    |
| `blaswrap.h`                 | Empty file — defeats dgesv's `f2c_` rename.   | sim-runtime               |
| `omhome-builtins/`           | Reduced ModelicaBuiltin.mo + NFModelicaBuiltin.mo, packed into `omc.data` MEMFS preload at `/omc/share/omc/ModelicaBuiltin.mo`. | omc-wasm |

## Why this directory exists

The PoC kept these shims in `src/`. During migration, `src/` will move
to `re-poc/src/` (frozen reference). New work lives here.

The split rationale: both projects need the GC stub, the rt_compat
stubs, and the BLAS extras. The omc-wasm-specific stubs (`omcweb_stubs*`,
`omc_config*`, `antlr3config.h`, `omhome-builtins/`) only get pulled
into omc-wasm's link; the sim-runtime build never references them.
Keeping them in one tree avoids the per-project drift the PoC was
already starting to hit (eg. `SystemImpl__stat` signature mismatch
between two parallel stub copies).
